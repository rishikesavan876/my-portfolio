Featured Project

Peer Project Hub

Overview

A full-stack platform where users can publish and explore coding projects, browse a shared feed, and manage their own submissions.

Problem

Student and junior developers often lack a simple, focused space to showcase individual projects and get visibility among peers.

Solution

Built a MERN application with secure authentication, owner-based permissions, and a clean project feed so users can create, edit, and manage their own listings.

Technologies

React.js, Node.js, Express.js, MongoDB, Mongoose, Firebase Authentication.

User authentication, project creation/editing/deletion, project feed, CRUD operations, MongoDB integration, owner-based authorization, RESTful APIs, responsive UI.
